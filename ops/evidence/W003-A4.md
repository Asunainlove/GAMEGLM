## 目标

缺口报告 C2：Boss 0.5 血两阶段切换在引擎内生效（`combat_engine.gd` `phase_change`
log），但切换无可感知 UI 表现。本包在表现层补齐（只消费引擎 log，不改引擎）：

1. 相位横幅：log `phase_change` → 屏幕上方 `"⚠ 相位失稳！{单位名}变了样子！"`（2s 淡出，红橙）。
2. 回合横幅：每回合开始 → `"第 N 回合"` 短横幅（1s；开局第 1 回合同样点亮）。
3. 战报面板：UI 右侧最近 3 条 log 中文摘要（行动名+目标+伤害/治疗数字，
   如 `"洛弦 → 漂移幼群：破尘击 6 伤害"`）；`error` 条目暗色显示。
4. 胜负横幅：finished → 全屏 `"胜利！"`/`"败北……"`（胜利金/败北暗紫），
   横幅期间输入锁定禁止再提交行动；`encounter_finished` 信号时序不变（见决策 1）。
5. 失稳标记：`destabilized` 单位色块闪紫 + 标签 `"失稳"`；`guard_ratio > 0`
   单位标签 `"防护"`。
6. 测试：本地 stub 引擎（`StubEngine`，static 签名与 CombatEngine 一致）经新增
   注入缝 `battle_scene.engine_script` 驱动 log 序列 → 横幅文本/可见性、战报面板、
   胜负横幅、行动禁用窗口、失稳/防护标签共 11 条新测试。

## 关键决策

1. **encounter_finished 信号时序裁定（任务书内部张力的消解）**：任务书同时要求
   "横幅 2s 后再回 game_session 卸载流程"与"保持 encounter_finished 信号时序不变"。
   实测约束：`tests/unit/test_integration.gd:592,608`（`_drive_battle()` 后同步
   `assert_null(session.battle)`）与 `tests/unit/test_integration_gap4.gd:351-352`
   （一帧内断言卸载+库存回写）——两文件均**不在本包允许路径内（禁改）**，且都依赖
   finish 当帧同步"落账+发信号→game_session 卸载"。故裁定：横幅在 `_finish_battle`
   内**先点亮**（同帧、先于落账），输入锁定生效后照常落账并同步一次性发信号；
   信号仍紧跟 director.finish 落账之后、仍恰好一次。2s 为横幅设计展示时长
   （Tween：保持 1.6s + 0.4s 淡出；场景存活期间完整播放，纯单元测试可断言可见性）。
2. **引擎注入缝**：`battle_scene.gd` 新增 `var engine_script: Script =
   COMBAT_ENGINE_SCRIPT`，全部引擎调用改经该引用（默认行为不变）；stub 引擎为
   测试文件内 inner class（`static var` 剧本模板 + `submit_action` 逐步消耗内嵌
   `stub_steps`），不含任何引擎结算逻辑。引擎本身零改动。
3. **战报摘要聚合**：`action` 条目与其后随 `damage`/`heal` 聚合为一行
   （`"行动者 → 目标：行动名 N 伤害"`，多目标/多效果用 `、` 连接），其余 log 类型
   各自成中文行（含 `defeated`/`destabilized`/`guard`/`item_used`/`round_start`/
   `battle_end`/`error` 等）；面板固定保留最近 3 条（滑动窗口）。
4. **失稳闪紫**：色块建节点时立即置紫（无帧依赖、可断言），`_process` 按正弦在
   基色与紫色间全幅摆动；摆色公式抽为纯静态函数 `destabilized_box_color(base, clock)`
   供确定性测试。`guard` 无色块变化（任务书仅要求标签）。

## 既有测试改动说明

**零改动。** 设计保证兼容：`encounter_finished` 仍同步一次性发出（集成测试的
卸载/回写断言不受影响）；UI 新节点为纯增量；单位标签仅在原文本尾部追加状态标签
（既有断言均为 `contains`）；`ActionsBox` 行为不变（仅 finish/锁定时清空，
与原 finished 清空语义一致）。

## 限制

1. **胜负横幅实际可见时长受卸载时点限制**：信号时序为硬约束（决策 1），真实
   游戏内 `game_session._on_encounter_finished` 当帧 `queue_free`，横幅可见时长
   ≈1 帧；2s 淡出动画在场景存活期间（单元测试、无 game_session 挂载时）完整播放。
2. 横幅/战报为 Label 文本级灰盒表现，无背板贴图/动效粒子（正式美术随 G6 里程碑，
   需溯源+人工审批）。
3. 战报中 `item_used` 不显示道具 id（避免英文 id 直出），仅显示数量；未知
   `action_id`/无名单位回退原始 id/"未知单位"。
4. 相位横幅在同一帧出现多条 `phase_change` 时仅显示最后一条（横幅语义即最新事件）。
