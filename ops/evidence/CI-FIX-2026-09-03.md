# CI fix 2026-09-03

## Symptom
First GitHub Actions run (`5867d19`) failed both jobs.

## Root causes
1. `content-schema`: YAML `run: |` heredoc closing `PY` was indented, so bash treated the script as an unclosed heredoc and exited 2 before `validate_content.py` ran. Local validation already PASSed (40 files / 65 defs / 14 schemas).
2. `toolchain-gate`: all 9 `addons/gut/**/*.png` were Git LFS pointers, but the LFS objects were never uploaded (batch API 404). Godot then failed `test_texture_at_loads_res_imported_texture` (707/708).

## Fix
- Restore binary PNGs from upstream GUT `v9.7.1`.
- Exclude `addons/gut/**/*.png` from LFS in `.gitattributes`.
- Simplify `content-schema` to `python scripts/validate_content.py`.
- Enable `actions/checkout` `lfs: true` on toolchain job for future project LFS assets.
