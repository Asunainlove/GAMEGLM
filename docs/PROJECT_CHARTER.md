# 《星壤：余辉纪元》垂直切片产品合同

## Goal

交付一个 Windows PC、离线单人、简体中文的 45–60 分钟 Godot 垂直切片：

> 探索采集 → 引导式建造锚居 → 世界/剧情变化 → 三场回合战斗 → 关系门控政策 → 地图、Boss、角色回应与结局变化 → 保存重载。

## Locked scope

- 一个 `4×2` Chunk 的琉砂海地区和一个手工矿井/Boss 区。
- 洛弦、弥砂两名成年原创核心角色。
- 三种材料、一个剧情核心、六个配方/建筑。
- 两种普通敌人、一个精英、一个两阶段 Boss。
- 三场固定战斗、一个星壤脉冲器。
- `station_mode`、`approach`、`policy` 三次选择；终局为开采、封存、共生，共生由洛弦信任解锁。

## Core hypothesis

玩家能够明确感知并复述：自己采集、建造和校准锚居的行为，改变了地图、角色立场、Boss 条件与结局，而不是只缴纳资源开门。

## Explicit non-goals

第二地区、第三角色、无限世界、随机 POI、角色恋爱/独立支线、等级装备、多人、移动端、账号、商城、Mod、LiveOps、DLC 和第二 Boss 均不在当前目标内。

## Completion

持续目标仅在 G7 Windows RC、自动验证、存档恢复、原创性审查和外部试玩门禁全部通过后完成。
