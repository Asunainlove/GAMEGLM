## 目标

- `EncounterDirector.check_triggers(start/static)`：数组序、flag 门控（due 置位 + 未置胜利旗标 + `battle_outcomes` 无该 id）。
- `EncounterDirector.start`：组装 CombatEngine config（allies 沙盒道具 / enemies / seed / unit_defs / action_defs / hp_multiplier + `encounter_id`），不调用引擎。
- `EncounterDirector.finish`：victory 单 patch 落账（record_battle_outcome + drops add_item + set_flag）；defeat 只记录失败（due 保留可重试）；store 注入（null → GameState）。

- 确定性：同遭遇同操作序列两次 → outcome 一致。

## 决策与限制

- **沙盒道具 battle_usable 判定**：`content` 契约键为 `unit_defs/action_defs/inventory/hp_multiplier`，未含物品定义；`start` 支持可选 `content.item_defs`——提供时按 `battle_usable` 数据判定，未提供（或该 id 无定义）时回退契约 §7 冻结的两个沙盒战斗道具 ID（`sedative_mist`/`shock_trap`）。两条路径均有测试锁定；真实调用方（集成层）建议从 ContentDB 供 `item_defs` 走数据路径。
- **道具数量语义**：按 WP12 决策 5，`item_ids` 数量按出现次数计；数量 = `min(出现次数, inventory 存量, 2)`，库存不足按存量、库存 0 或非 battle_usable 不装配。测试与 WP12 `EXPECTED_ALLY_ITEM_COUNTS` 一一对应。
- **finish 为实例方法**：任务书仅 `check_triggers`/`start` 标注 static，`finish` 为实例方法——场景端 `_finish_battle` 经 `DIRECTOR_SCRIPT.new()` 实例化调用（纯逻辑无状态）；对 Script 资源直接调实例方法会触发引擎 `!is_static` 错误并静默返回 null（第一轮 GREEN 实测记录在案）。
- **目标自动选择**：`single_enemy` → 第一活敌（引擎 `order` 序，即速度 desc、同速 key 字典序）；`single_ally` → 最低 hp 活友（平局取 order 靠前，与引擎 AI 规则一致）；`self`/`all_enemies` → 空目标（引擎校验接受）。
- **敌方回合自动结算**：引擎 `submit_action` 已内置"结算后推进并连续结算敌方回合直到 ally 或结束"；场景层循环仅兜底"开局先手为敌方"（如 Boss 速度 7 高于盟友）与异常边界，带 64 次安全上限。
- **灰盒实现细节**：单位节点命名 `key.replace("|","_")`（如 `a0_luoxian_fighter`）并加入 group `battle_unit`；行容器 `Row_front/Row_mid/Row_rear` 运行时懒创建；刷新采用同步 `free()`（树外节点 `queue_free` 不生效，且保证同帧计数准确），按钮按下经 `call_deferred` 规避"发射信号过程中 free 发射者"。残留孤儿节点（2 个）来自 WP08 既有 `test_narrative_dialogue_box.gd`，与本包无关。
- **`encounter_finished` 语义**：无论 `director.finish` 落账成败都发出（信号表示战斗流程结束）；落账结果经 `last_finish_result()` 暴露，测试断言其 `is_ok`。`store` 无 `snapshot()` 方法时以空 state（revision 0）构造 source_id——DuckStore 场景下的退化路径。
- **`Progression.boss_hp_multiplier`**：WP14 未合并；场景只透传 `content.hp_multiplier`（任务书"你只透传"），Boss 血量倍率由调用方决定。
- **确定性范围**：引擎 AI 与 seed 无关（WP10 已锁定）；本包锁定"同遭遇 + 同操作序列 → outcome 完全一致"，`seed` 仅透传用于 `battle_id` 命名。
- **允许路径遵守情况**：仅新增 `src/encounters/**`、`scenes/battle.tscn`、`tests/unit/test_encounters_director.gd`、`tests/unit/test_encounters_battle_scene.gd`（+.uid）与本文档；未触碰 `project.godot`、主检出或其他 worktree。
