### A.2 每路线检查点清单（逐项 ☐）

**公共链路（三路线均适用，每路线各勾一组或注明复用）：**
- ☐ 启动至可操作世界 ≤ 60 秒；序章降落事件自动触发
- ☐ 引导提示按序出现（移动/放置/合成/覆盖层）
- ☐ 首次采集（`first_mining_done`）→ 建造引导 → 锚块 + 锚居工坊
- ☐ 采集→建造→供电门控可感知（BuildBar 断电红点、回响舱需房间+供电）
- ☐ 建造并供电尘精炼器、稳定塔、共鸣织机；回响舱激活（`echo_chamber_active`）
- ☐ 三场遭遇按序可触发并取胜：`encounter_first_drift`、`encounter_husk_ambush`、`encounter_leviathan`
- ☐ Boss 两阶段横幅出现；战斗 UI（战报/失稳标记）可用
- ☐ 三次选择均出现且角色回应台词随选择变化
- ☐ 信任面板数值可见（政策门 40 提示）

**开采线：**
- ☐ `station_mode_exploit` / approach_direct / policy 配额
- ☐ exploit 选择后矿脉富集可感知（世界回应重生成）
- ☐ 开采配额后 Boss 血量 ×1.2 可感知
- ☐ 结局文案「结局：开采纪元」

**封存线：**
- ☐ 同上公共链路全部 ☐
- ☐ `station_mode_seal` / approach_diplomatic / quota
- ☐ approach_diplomatic 触发 `event_envoy_trust`（信任 +5 分支）
- ☐ 结局文案「结局：封存之约」

**共生线：**
- ☐ `station_mode_symbiosis` / approach_direct / `policy_sanctuary`
- ☐ sanctuary 政策可选（信任 ≥40 时解锁；不足时禁用态文案可见）
- ☐ 共生门提示「距离共生还需 X 点」随信任推进消失
- ☐ 洛弦信任 ≥70 + 回响舱激活 → 结局文案「结局：共生曙光」
- ☐ （对照）信任 69 或未激活回响舱 → 回落「结局：封存之约」（可选单独读档验证）
