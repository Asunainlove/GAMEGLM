## 决策与限制

1. **青→金的语义迁移**：任务书锁定"深空灰底+余辉金高亮"，而灰盒主题高亮为青色
   （#6BC9B8）。裁定：金为唯一交互高亮，青降级为"电力/能量"语义色（保留在成本
   电耗数字等场景），并给出单资产金面积 ≤15%、红金不同框的防滥用规则（§0.1）。
2. **title_screen.gd 未合入**：§7 按任务书规划撰写；挂点列留待并行包合入后复核
   回填（§0.5 与 §7 章首均已标注），尺寸按 1280×720 视口不受影响。
3. **战报面板为规划新增节点**：battle 现场无 BattleLog 节点，§8.3 已标注"挂点名以
   战斗 UI 集成包为准"，避免文档与代码漂移误导集成。
4. **微软雅黑授权边界**：SystemFont 运行时兜底可用，但任何可分发固定版式成品
   （LOGO/宣传图）禁用；LOGO 推荐路径为思源黑体 Heavy 骨架手工重绘成原创字标 +
   UI 正文内嵌 OFL 思源黑体（附许可证全文与 THIRD_PARTY_NOTICES 条目要求，§0.2/§7.1）。
5. **`assets/` 目录未创建**：目录结构属规范内容，物理创建随首个资产入库的集成包
   执行（§10.2 已注明），本包严守允许路径。
6. 打字机效果、战报面板、背包网格化为规划功能，对应资产（光标/战报/槽位网格）
   已按"资产先行"惯例给出规格并标注依赖关系（§6.4/§8.3/§4.1）。
