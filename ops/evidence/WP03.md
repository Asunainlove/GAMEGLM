## 决策与限制

- **矿脉数界**：要求"每脉随机游走 3~8 格"与"总数 60..120"存在张力（10×3=30 < 60）。实现取"3~8 步随机游走成簇 + 每脉补齐到 ≥6 个独占格"，构造性保证每脉 6..9 格、总数 60..90 ⊂ [60,120]；跨脉首写者胜（不重染、不计数），重叠不会击穿下界。
- **seed 混合**：`RandomNumberGenerator.seed = hash("%d|%s" % [world_seed, chunk_id])`。GDScript String hash 在同一 Godot 构建内跨进程/平台确定性；存档不存 chunk 哈希，仅存 delta，风险面小。
- **矿型分布**：40/40/20 按每脉 rng 掷点实现（概率性而非每 chunk 硬配额 4/4/2）；测试断言固定 seed 集合上三种类型均出现（确定性验证，不抖动）。
- **渲染边界**：`WorldRenderer.render()` 每次先 clear 双层再全量重绘；`apply_deltas` 只擦不绘。world 只在 `_ready` 渲染一次 chunk_0_0，之后仅走 delta 擦除，二者不会互相覆盖。多 chunk 平移渲染、世界 seed 变更后重生成留待后续包。
- **快照轮询**：Timer 0.5s 比对 `revision`，变化即 `refresh_from_snapshot()`（公开可测）；provider 注入（`snapshot_provider: Callable`，默认 `GameState.snapshot`）；provider 返回非 Dictionary 时告警回落 GameState。表现层全程只读，不改持久状态。
- **player.tscn 缺失**：`ResourceLoader.exists` + `PackedScene` 双重守卫，缺失/加载失败/实例化为 null 均 push_warning 跳过；`@export player_scene_path` 可注入。当前 worktree 该文件不存在（WP02 未合并），日志中 9 条 expected warning 即此路径的证明；合并后自动生效，相关测试对"已合并"形态做了条件断言，不会误报。
- **基线口径**：本 worktree 基点为合约冻结 commit（26 测试/205 断言），任务简报所述"基线 122 测试"与并行合并后的 main 状态对应，不在本包内执行合并；本包交付后套件为 50/50。
- `TileMapLayer` API（Godot 4.7）：`set_cell(coords, source, atlas)`、`get_cell_source_id`、`get_used_cells`、`clear()`；TileSet 经 `Image.create_empty` + `ImageTexture.create_from_image` 运行时生成，无二进制美术资产，符合灰盒要求。
