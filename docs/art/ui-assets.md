## 0. 全局设计令牌（所有章节共享，单一定义源）

### 0.1 色彩令牌

延续灰盒主题 `themes/starsoil_theme.tres` 的深空灰底；把灰盒期的青色边框升级为
**余辉金**作为唯一交互高亮语义色。青色 `#6BC9B8`（现 StyleBox 边框色）**降级保留为
"电力/能量"语义色**（供电线路、BuildBar 成本中的电耗数字），不再用于按钮与面板高亮。

| 令牌 | 值（sRGB Hex） | 对应灰盒值（延续依据） | 语义 |
|---|---|---|---|
| `bg.deep` | `#0B111C` | — | 全屏底色 / 遮罩 scrim（不透明度 92%） |
| `bg.panel` | `#121A26`（96% 不透明） | `Color(0.07, 0.095, 0.14, 0.96)` | 所有面板基底"深空灰" |
| `bg.panel-raised` | `#18222F` | 按钮 normal `Color(0.16, 0.2, 0.26)` | 槽位、按钮浮起面 |
| `bg.pressed` | `#10161F` | 按钮 pressed `Color(0.12, 0.16, 0.2)` | 按压/凹下面 |
| `gold.main` | `#E8C878` | hover 字色 `Color(0.98, 0.95, 0.82)` 的落定色 | **余辉金主高亮**：边框、选中、光标 |
| `gold.bright` | `#F7E6B0` | — | hover 泛光、标题描金 |
| `gold.dark` | `#9A7B3F` | — | 按下态边框、disabled 描边 |
| `text.primary` | `#DBE6EB` | `Color(0.86, 0.9, 0.92)` | 正文 |
| `text.secondary` | `#93A7B4` | — | 成本摘要、次要说明 |
| `text.disabled` | `#5C6B76` | — | 禁用文案 |

| `semantic.danger` | `#D92626` | `UNPOWERED_DOT_COLOR Color(0.85, 0.15, 0.15)` | 断电红点、危险按钮、不可合成 |

`semantic.teal` 与 `gold.*` 不得在同一构件上同时作边框色。

### 0.2 字体与字号

- 灰盒现状：`SystemFont("Microsoft YaHei UI", "Microsoft YaHei", "SimHei")`，默认 14px。
  系统字体仅用于灰盒过渡，**正式版必须内嵌开源字体**（见 §7.1 授权说明）。
- 内嵌建议：**思源黑体 Source Han Sans SC（SIL OFL 1.1）**，Regular + Bold 两个字重，
  TTF/OTF 子集化后入 `assets/fonts/`；必须在 `THIRD_PARTY_NOTICES.md` 追加 OFL 条目并
  随包附带完整许可证文本（OFL 要求：保留版权声明与许可文本，禁止单独出售字体文件本身）。
- 字号阶梯：正文 14 / 面板标题 18 / 界面标题 20 / 横幅 22 / LOGO 为字标图形（非字体排版）。
- 行高 1.4；中文排版禁止自动断词悬挂，`autowrap_mode = 3` 场景（对话框正文、帮助文案）
  需在底图上预留右缘 8px 避让。

### 0.3 九宫格（9-patch）通则

- Godot 接入方式二选一：`StyleBoxTexture`（主题内）或 `NinePatchRect`（独立节点），
  两者均通过 `texture_margin_left/top/right/bottom` 指定边距；本文给出的
  **9-patch 边距标注为 `(L, T, R, B)` 像素值**，源图四角区域即被锁定的圆角+描边+泛光带。
- 源图交付尺寸 = 标注中的"源图尺寸"，运行时被拉伸到"运行时包框"；四角 1:1 保真，
  边缘单向拉伸，中心双向拉伸——中心区必须是无渐变纹理的纯色/微噪点，否则拉伸会产生可见条纹。
- 圆角统一 6px（灰盒为 4px，视觉升级但不破坏布局）；描边 1px 居中于边距带内。
- 所有 9-patch 源图按"设计尺寸 1:1"导出，禁止运行时缩放补偿。

### 0.4 资产 ID 命名规则

- 格式：`UIA-<类别>-<名称>`，全大写、连字符分隔；类别码：
  `PNL` 面板 / `BTN` 按钮 / `HUD` 顶部与提示 / `INV` 背包 / `BLD` 建造栏 /
  `DLG` 对话框 / `TTL` 标题界面 / `BAT` 战斗 / `ICO` 图标。
- 同一资产多尺寸：后缀 `-S / -M / -L`；多状态以状态表描述，不拆 ID。
- 文件名 = 资产 ID 转全小写 snake_case（如 `uia_pnl_dialogue.png`），与项目
  `snake_case` ID 惯例一致。

## 1. 九宫格面板（4 种 PanelContainer/Panel 皮肤）

共享风格语言：`bg.panel` 深空灰底 + 1px `gold.main` 外描边 + 外侧 2px `gold.main` 12% 泛光带 +
顶部内缘 1px `gold.bright` 20% 顶部受光线。四角 6px 圆角。中心区纯 `bg.panel` 带极轻噪点
（≤3% 明度扰动，防条带）。四张面板为同一族但**不可互相替换**：对话框横长、背包方正、
菜单窄高、帮助为菜单内嵌凹面板（反高亮：描边改 `#2A3644` 内凹线）。

- **用途与挂点**：`dialogue_box.tscn → DialogueBox/Panel`（现为裸 Panel）。
- **尺寸与格式**：源图 96×96 PNG（9-patch 边距 `(28, 24, 28, 28)`）；运行时包框 1184×204
  （下缘距屏底 28px，左右各留 48px，与现场景偏移一致）。附 SVG 源。
- **风格语言**：深空灰底 + 余辉金细描边；对话框是叙事主舞台，泛光带略强于其他三张（18%）。
- **构图要素**：左上角留出姓名牌咬合缺口区（§6.1 的牌体压在面板上沿，源图无需开槽，

- **状态差分**：单态（对话面板无 hover 语义；出现时建议由集成层做 8px 上浮淡入，不入图）。

### 1.2 UIA-PNL-INVENTORY 背包面板

- **验收标准**：480×440 下与现有 `ItemsBox`/`RecipesBox` 4px 行距叠加不溢出；

### 1.3 UIA-PNL-MENU 菜单面板

## 2. 按钮组（4 变体 × 3 尺寸，每变体含 normal/hover/pressed/disabled 四态）

共享风格语言：圆角 6px、1px 描边、内容边距 `(12, 6)`（S 尺寸减半为 `(6, 3)`），
与现主题 StyleBoxFlat 尺寸参数一致以保证替换后布局不跳。**四态差分通则**：

| 态 | 底色 | 描边 | 字色/内容色 |
|---|---|---|---|
| normal | `bg.panel-raised` `#18222F` | `#5C6B76`（灰） | `text.primary` |
| hover | `#202B3A`（亮一档） | `gold.main` | `gold.bright`（延续现 hover 字色暖金） |
| pressed | `bg.pressed` `#10161F`（内凹，顶部受光线移除） | `gold.dark` | `gold.main` |
| disabled | `#141B26`（扁平） | `#2A3644` | `text.disabled` |

选中（toggle）变体在四态之上叠加常驻标识：`button_pressed = true` 时底色混入
`gold.main` 8%、描边恒为 `gold.main`（即使处于 hover/pressed 覆盖态）。

三尺寸（高 × 最小内容宽，9-patch 边距一律 `(10, 8, 10, 8)`，源图 48×32）：
- **-S**：高 24，合成按钮、配方行内按钮（现"合成"按钮）、战斗道具按钮。
- **-M**：高 36，菜单四按钮（现 `custom_minimum_size = 36`）、对话框选项按钮。
- **-L**：高 48，标题界面主按钮、战斗主行动按钮。

每尺寸交付 4 态独立 PNG + 每变体一份 SVG 主文件（尺寸参数化导出）。

### 2.1 UIA-BTN-STD-{S,M,L} 标准按钮（普通）

- **用途与挂点**：全局默认 Button 皮肤（`starsoil_theme.tres` 的 `Button/styles/*` 替换）；
  覆盖 `ResumeButton/SaveButton/HelpButton`。
- **构图要素**：无边框内纹样；hover 时顶部出现 1px `gold.bright` 内受光线；
  pressed 整体下沉 1px（图内表现，不加代码偏移）。
- **状态差分**：normal / hover / pressed / disabled（通则表逐项落实）。
- **验收标准**：三尺寸四态共 12 图 + SVG；文本 14/16px 双字号下文字与描边间距 ≥6px；
  与灰盒 StyleBoxFlat 并排对比无布局位移。
- **优先级**：P0 ｜ **预估工时**：9 人时（3 尺寸 × 4 态）

### 2.2 UIA-BTN-SELECTED-{S,M,L} 选中按钮（toggle 选中态）

- **用途与挂点**：`Hud/BuildBar → BuildSlot_<id>`（`toggle_mode = true`）；
  标题界面"继续"（有存档时的默认焦点项可复用）。
- **构图要素**：std 基础 + 左缘 3px `gold.main` 竖条 + 底色 8% 混金；
  竖条是"当前选中"的唯一识别符（不得再用角标/星形）。
- **状态差分**：selected-normal / selected-hover / selected-pressed（disabled 与 STD 共用）。
- **验收标准**：`button_pressed = true/false` 两态切换时视觉跳变 ≤ 1px；
  竖条在 9-patch 中位于左角区（不参与拉伸）。
- **优先级**：P0 ｜ **预估工时**：9 人时

### 2.3 UIA-BTN-DISABLED-{S,M,L} 禁用按钮

- **用途与挂点**：配方行不可合成（`craft_button.disabled`）、对话框信任不足选项、
  无存档时的标题界面"继续"。
- **构图要素**：通则 disabled 态 + 中央 45° 细斜纹（`#2A3644`，间距 6px，宽 1px）——
  在色弱条件下与 normal 可区分的第二通道。
- **状态差分**：单态（disabled 不响应 hover/pressed；斜纹静态）。
- **验收标准**：与 UIA-BTN-STD 同尺寸并排，灰度打印仍可区分；
  斜纹不干扰 14px 文案可读性（文字区 40px 内无斜纹）。
- **优先级**：P0 ｜ **预估工时**：6 人时

### 2.4 UIA-BTN-DANGER-{S,M,L} 危险按钮

- **用途与挂点**：`MenuPanel/Content/RestartButton`（重新开始，会清当前进度）、
  后续战斗投降/撤退类操作。
- **构图要素**：描边与 hover 边框改用 `semantic.danger`（`#D92626`），
  底色 `#241418`（红调深底）；hover 泛光为红。
- **状态差分**：normal / hover / pressed / disabled（disabled 复用 §2.3）。
- **验收标准**：`RestartButton` 上无歧义传达"破坏性操作"（红描边在 normal 态即出现）；
  与 gold 系按钮同屏不冲突（红金不同框）。
- **优先级**：P0 ｜ **预估工时**：9 人时

## 3. HUD 元素（顶部物品栏 / 目标横幅 / 提示 / 保存提示）

共享风格语言：HUD 元素一律 9-patch 或单图，底 `bg.panel` 88% 不透明（比面板更透，
保证世界可见性）；高亮金只出现在目标横幅与选中槽。挂点均为 `ui_hud.tscn → Hud`。

### 3.1 UIA-HUD-SLOTFRAME 物品槽框（8 槽 + 1 堆叠徽章）

- **用途与挂点**：`Hud/InventoryBar`（现为文本行 `名 ×n`，升级为 8 槽框；
  第 9 种是溢出徽章"+N"，对应代码 `MAX_BAR_SLOTS = 8` 与 `overflow_kinds` 分支）。
- **尺寸与格式**：槽框 40×40 单图 ×1（8 槽复用同图，程序排布 HBox 间距 4）；
  溢出徽章 24×16 单图（圆角胶囊）。PNG + SVG。
- **风格语言**：`bg.panel-raised` 内凹槽（顶部 1px 暗线、底部 1px 亮线的反真凹槽），
  外描边 `#2A3644`；拾取反馈的金高亮由集成层做 0.2s 描边闪金（帧序列不在本资产内）。
- **构图要素**：槽内左上留 32×32 图标位（§3.2）；徽章居中白色 `+N` 数字（14px）。
- **状态差分**：两态——空槽 / 已占用（占用态 = 空槽 + 图标与徽章由程序叠加，
  底图相同；空槽右上角留 8×8 锁定位供后续扩展）。徽章单态。
- **验收标准**：8 槽 + 徽章总宽 ≤ 8×40 + 7×4 + 8 + 24 = 364px（不越过 1280 宽度预算）；
  40×40 下 32px 图标居中误差 ≤1px；徽章数字可读。
- **优先级**：P0 ｜ **预估工时**：6 人时（槽框 4 + 徽章 2）

### 3.2 UIA-HUD-ICON-BASE 物品图标底座

- **用途与挂点**：`Hud/InventoryBar` 槽内、`InventoryPanel/Content/ItemsBox` 行首。
- **尺寸与格式**：32×32 单图（内置 28×28 内容安全区）；另导 64×64 备用（背包详情位）。
- **风格语言**：`bg.deep` 圆角 4px 底 + 1px `#2A3644` 框 + 右下 4px `gold.dark` 20% 内阴影；

- **状态差分**：两态——正常 / 按钮焦点联动微光（集成层做 4% 亮度脉动，图同）。

### 7.2 UIA-TTL-BTNRAIL 标题按钮排布

- **尺寸与格式**：复用 UIA-BTN-DANGER-L（退出）/ UIA-BTN-STD-L（新游戏）/

- **风格语言**：按钮列整体置于画面左下三分之一交点（非对称布局，延续研究报告中

- **构图要素**：三钮纵向间距 20px；"继续"无存档时使用 §2.3 disabled 态（集成逻辑）。

- **验收标准**：1280×720 下按钮列不与 LOGO 重叠；键盘 Tab 焦点环（复用 hover 图）

### 7.3 UIA-TTL-BG 标题背景

- **用途与挂点**：标题界面全屏底图。
- **尺寸与格式**：2560×1440 PNG（下采样至 1280×720 使用）+ 分层 PSD/SVG 源
  （前景晶体层 / 中景矿脉层 / 天空层，供未来做视差）。
- **风格语言**：研究报告视觉语言落地：**琉砂海黄昏——深空灰蓝的天空向地平线过渡到
  余辉金尘暴光带；前景剪影为原创的晶簇矿脉与半埋的古代工程结构（拱形锚点遗迹）；
  光效统一使用"星壤光"：从晶簇内部发出的金暖内透光**。禁止出现任何现有游戏场景
  的标志性构图（浮空环、星穹列车等一律回避）。
- **构图要素**：地平线位于画面下 1/3；左下 1/3 交点区域（按钮落位）刻意压暗做
  信息安全区；右上为 LOGO 预留的相对干净的天空区；无角色出场（角色立绘属独立
  资产包，不在此合同内）。
- **状态差分**：两态——静态主图 / 10% 亮度压暗版（版本选择或菜单弹出时衬底用，
  也可由程序叠加遮罩实现，压暗版为可选交付）。
- **验收标准**：1280×720 下天空过渡无条带（16bit+ 输出或抖动）；按钮安全区内
  文字对比 ≥ 7:1；原创性审查通过；文件 ≤ 2.5MB（BC 压缩前）。
- **优先级**：P0 ｜ **预估工时**：10 人时

## 8. 战斗 UI（`battle.tscn → UI` CanvasLayer + `Tracks`）

现状锚点：`UI/TurnLabel`（左上"第 N 回合"）、`UI/ActionsBox`（左下 240×172 按钮列）、
`Tracks`（单位为 56×40 灰盒块，按 `front/mid/back` 三轨排布，`UNIT_SPACING` 横距、
`ROW_SPACING` 纵距）。Boss 有 `phases[].at_hp_ratio` 相位切换（`phase_index` 锁存）。

### 8.1 UIA-BAT-ACTIONBTN 行动按钮

- **用途与挂点**：`UI/ActionsBox` 内程序生成 Button（文案取 `action_defs.name_zh`：
  攻击/防御/道具等）。
- **尺寸与格式**：UIA-BTN-STD-M 240×36 加宽变体 + 一套 16×16 行动小图标位
  （攻击/防御/道具 3 枚，`gold.main` 线性，程序按 action 类型叠加）。
- **风格语言**：std 按钮；仅敌方行动阶段整列隐藏（代码现状），无按钮级差分。
- **构图要素**：图标位 + 文字。
- **状态差分**：normal / hover / pressed / disabled（继承 std 四态；disabled 用于
  非当前行动单位占位时）。
- **验收标准**：172px 高内至少完整显示 4 个按钮；图标不与任何现有游戏行动图标雷同。
- **优先级**：P0 ｜ **预估工时**：4 人时

### 8.2 UIA-BAT-TRACKS 轨道排布底图

- **用途与挂点**：`Tracks` 节点下、单位灰盒块之下的战场地面。
- **尺寸与格式**：1280×560 PNG（非 9-patch，整图构图）；另交 3 条 1120×4 轨道
  分隔虚线（front/mid/back，`#2A3644`）。
- **风格语言**：俯视 30° 抽象化战场地面：三条横向矿脉轨道（对应三排），我方
  （左）与敌方（右）以地面色温区分——我方侧偏冷灰、敌方侧偏暖赭，中轨最亮
  （近战焦点）；余辉金只用于地面晶脉点缀（≤5% 面积）。
- **构图要素**：三轨带、两侧出发区微亮框（单位落位视觉引导）、四角渐晕。
- **状态差分**：单态；Boss 相位切换时地面光色由集成层换暖（同图加色罩，P2）。
- **验收标准**：56×40 单位块 + 18px 头顶血条文本落在轨道带上均可读；
  三轨纵向间距（`ROW_SPACING`）与图内轨带间距一致（集成前需对照代码常量复核）。
- **优先级**：P1 ｜ **预估工时**：8 人时

### 8.3 UIA-BAT-LOG 战报面板

- **用途与挂点**：规划节点（建议 `UI/BattleLog` 右侧 360×200 PanelContainer；
  现代码无此节点，属新增——挂点名以战斗 UI 集成包为准）。
- **尺寸与格式**：9-patch 源图 80×80，边距 `(24, 24, 24, 24)`；运行时 360×200。
- **风格语言**：`bg.panel` 85% + `#2A3644` 描边（无金——战报是信息流，不是焦点）；
  伤害数字由程序染 `gold.bright`，受击染 `semantic.danger`。
- **构图要素**：顶部 20px 标题带"战报"+ 滚动文本区。
- **状态差分**：单态。
- **验收标准**：200px 高容纳 ≥8 行 12px 战报；半透明底不遮挡右侧敌方轨道。
- **优先级**：P1 ｜ **预估工时**：5 人时

### 8.4 UIA-BAT-BNR-{PHASE,TURN,RESULT} 横幅 3 种

- **用途与挂点**：均为规划节点（建议 `UI/Banner` 单节点复用三图）：
  相位横幅（Boss `phase_change` 时）/ 回合横幅（每回合开始）/ 胜负横幅（战斗结束）。
- **尺寸与格式**：
  - 相位 `UIA-BAT-BNR-PHASE`：9-patch 96×48，边距 `(32, 24, 32, 24)`；运行时 640×96。
  - 回合 `UIA-BAT-BNR-TURN`：9-patch 64×32，边距 `(24, 16, 24, 16)`；运行时 320×64。
  - 胜负 `UIA-BAT-BNR-RESULT`：9-patch 96×48，边距 `(32, 24, 32, 24)`；运行时 720×160。
  均附 SVG。
- **风格语言**：
  - 相位：**红色系警戒横幅**——`#241418` 底 + `semantic.danger` 双线框 + 中央
    裂纹状分割线（Boss 进入新相位的威胁感）。
  - 回合：极简细带——`bg.deep` 90% + 1px `gold.main` 框 + 两侧对开细线。
  - 胜负：**金底纪念横幅**——胜利态 `gold.dark` 底 + `gold.bright` 双线框 +
    上下 4px 流光带；失败态同构但底改 `#141B26`、线改 `#5C6B76`（灰败）。
- **构图要素**：中央文字区（22px，"第二相位""第 3 回合""胜利/战败"由程序填充），
  横幅两端菱形微标（星壤 motif 终章）。
- **状态差分**：相位/回合各单态；胜负两态（胜/败）。出场动画（0.25s 横向展开）
  集成层实现。
- **验收标准**：三横幅在 1280×720 中央叠放时互不越界；红金两色不混用于同一横幅；
  胜负横幅出现时其下所有按钮已隐藏（代码 `is_finished` 清空 ActionsBox 的行为一致）。
- **优先级**：P0 ｜ **预估工时**：9 人时（3×3 人时）

## 10. 资产管线（导出格式 / 目录 / 导入设置 / 溯源审批）

### 10.1 导出格式

| 用途 | 交付格式 | 说明 |
|---|---|---|
| 引擎使用 | PNG（RGBA8，无损） | 唯一入引擎格式；命名 `uia_<类别>_<名称>[_<尺寸>][_state].png` |
| 矢量源 | SVG 1.1 | 所有 9-patch、徽章、图标、LOGO 必须有 SVG 源（9-patch 边距值写入 SVG 图层名） |
| 分层源 | PSD / Krita / Orora | 仅背景（§7.3）与横幅（§8.4）要求分层交付 |
| 位图母版 | 256×256 PNG | 图标类母图（降采样源） |

禁止：JPEG（UI 硬边会振铃）、WebP（Godot 4 可导入但本项目统一 PNG 以简化溯源 diff）。

### 10.2 目录结构

```
assets/art/ui/
├─ panels/          # §1 四张 9-patch 面板
├─ buttons/         # §2 按钮组（按变体分子目录 std/selected/disabled/danger）
├─ hud/             # §3
├─ inventory/       # §4
├─ buildbar/        # §5
├─ dialogue/        # §6
├─ title/           # §7
├─ battle/          # §8
├─ icons/           # §9（32/64/256 三档）
└─ _source/         # SVG / PSD 源 + PROVENANCE.md；根目录放 .gdignore（引擎不导入）
```

- `assets/` 目前不存在，本包批准后由集成包随首个资产批量创建（`docs/art/` 与
  `assets/art/` 分属文档与资产，互不混放）。
- 每个资产目录内允许存在同名 `-hover/-pressed/-disabled` 状态文件；状态表（各章节）
  是状态文件名的唯一权威。

### 10.3 Godot 导入设置（9-patch / Slice）

- 通用：`CompressedTexture2D`，压缩模式 **Lossless**；`mipmaps = false`；
  `filter = Linear`（UI 全部为矢量感资产，禁用 Nearest）。
- 9-patch 接入优先级：主题内一律 `StyleBoxTexture`（`texture_margin_l/t/r/b` 取
  各资产标注值）；独立节点（如 `DialogueBox/Panel` 从裸 Panel 升级）用
  `NinePatchRect`（`patch_margin_*` 同值）。**边距值唯一来源是本文各资产标注，
  导入时不得目测改值**。
- SVG：仅 `assets/fonts` 与 `_source` 之外不直接入引擎；若未来改由引擎直导 SVG，
  `scale = 1.0` 且逐文件复核光栅化结果与 PNG 交付一致。
- 主题迁移：`starsoil_theme.tres` 的三个 StyleBoxFlat（panel / button 三态）在
  §1/§2 资产 approved 后替换为 StyleBoxTexture；`Panel/styles/panel` 与
  `PanelContainer/styles/panel` 分别绑定 UIA-PNL 族（对话框 Panel 节点独立
  override）。替换提交必须附 UI 截图对照（灰盒 vs 正式）。

### 10.4 溯源与审批（AGENTS 硬性门禁）

- 状态流：`raw`（生成/绘制完成）→ `review`（自检通过，进入对照评审）→
  `approved`（协调者或指定验收人签字）→ 入引擎。**未经 approved 的资产禁止
  被任何 `.tscn/.tres` 引用。**
- 溯源账本：`assets/art/ui/_source/PROVENANCE.md`，逐资产记录：资产 ID、作者/工具、
  源文件路径与哈希、生成提示词（若使用图像生成）、审批人与日期、许可能力
  （原创 / OFL / 商用授权凭证编号）。
- 原创性审查清单（每资产过一遍）：不复制现有游戏角色/轮廓/UI/图标/术语/Logo；
  不模仿在世艺术家签名风格；LOGO 与背景（§7）另需对照"禁止事项"专项复核。
- 字体合规：内嵌思源黑体时，`THIRD_PARTY_NOTICES.md` 追加 OFL 条目 + 随包
  `assets/fonts/LICENSE-SourceHanSans-OFL.txt` 全文；微软雅黑仅作为运行时
  SystemFont 兜底存在，不出现在任何分发图像成品中（§7.1）。

### 10.5 交付顺序建议（依赖驱动）

1. 批次一（解锁全部皮肤替换）：§2 按钮组 → §1 面板 → 主题迁移。
2. 批次二（核心循环反馈）：§5 建造栏 + §3 HUD → §4 背包 → §6 对话框。
3. 批次三（演出层）：§9 图标 → §8 战斗 → §7 标题（LOGO 草稿可提前并行）。
