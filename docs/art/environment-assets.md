### 0.2 风格总纲（双分辨率视觉语言）

- **环境 = 高清像素**：所有 32/48 px 级 tile 与精灵为像素艺术（建议有效笔刷 1–2 px，禁止半透明抗锯齿糊边；发光效果允许受控的 1 级柔光）。
- **远景插画 = 高清栅格**：§6 三张 1920×1080 远景为手绘感栅格插画，与环境像素层构成有意设计的"双分辨率视觉语言"，靠以下手段统一：同一色彩脚本、同一种星壤辉光、同一组晶族图形符号。
- **琉砂海色彩脚本**：终稿色相以 0.1 表灰盒五色为**色相锚点**（色相偏移 ≤ 15°，明度/饱和度可按美术需要放开）。全局基调为"永暮余辉"——低角度暖橙余辉光 + 冷青蓝阴影的柔和冷暖对照；母题关键词：星壤晶体、破碎世界、光学仪器、古代工程、宇宙考古、文明废墟。
- **昼夜口径**：切片锁定永暮基调，**无昼夜系统**。本文各资产的"昼夜差分"一律按"无独立昼夜图，全局色调由 CanvasModulate 承担（建议恒 `#FFF4E8` 暖白，不做动态切换）"处理；有状态需求的资产以**状态差分**（供电/断电、休眠/激活、完好/破坏）替代，逐条写明。
- **原创性红线（硬约束，源自 AGENTS.md）**：
  1. 禁止请求、模仿任何**在世画师**的个人风格；禁止"画成某商业游戏"式提示词。
  2. 禁止复制现有游戏的角色、剪影、UI、图标、术语、Logo、品牌元素。
  3. 图面禁止出现文字、水印、签名、Logo。
  4. 全部资产须有溯源记录（提示词文件 + source_model）并经**人工审批**后方可置为 `approved` 入库。

### 0.3 优先级与工时口径

- **P0**：采集—建造核心循环直接依赖，缺则切片不可验收。
- **P1**：氛围、叙事与区域识别，缺则体验降级但可玩。
- **P2**：打磨项，可延后到 G7 前。
- 工时单位：**人日**（1 人日 = 6 有效工时），含修改一轮；不含程序接线（接线需求见 §9.5，由协调者另派程序包）。

### 0.4 资产 ID 与文件命名（详规见 §9.1）

`env_<域>_<对象>_<描述>`，全小写 snake_case、仅 ASCII；状态后缀 `_s0..s2`（破坏态）、`_powered/_unpowered`、帧后缀 `_f0..`；图集后缀 `_atlas`。本文所有资产 ID 已按此规范给定，**交付时不得改名**。

## 9. 资产管线

### 9.1 命名规范

- 格式：`env_<域>_<对象>_<描述>[_<状态|帧|变体>][_v<NN>]`；全小写 snake_case、ASCII、无空格。
- 域枚举：`world`（地表/矿/墙/地面）、`overlay`（勘测覆盖）、`mine`（矿井专属）、`bg`（远景）、`bld`（建筑）、`border`（边界）、`fx`（特效）、`decal`（贴花）。
- 语义后缀：状态 `_s0/_s1/_s2`、电力 `_powered/_unpowered`、激活 `_dormant/_active`、帧 `_f0..`、平铺变体 `_tile0..`、方向 `_n/_e/_s/_w`。**禁止**中文名、大写、空格、日期戳；版本演进用 `_v02` 新文件，不覆盖已审批文件。

### 9.2 目录结构

```text
assets/
└─ art/
   ├─ world/
   │  ├─ tiles/          # ENV-01..03, 04..06, 07..11, 12..14, 28（TileSet 图集）
   │  ├─ buildings/      # ENV-21..26（含 96×48 合并图集）
   │  ├─ fx/             # ENV-15..17, 27（碎裂帧/粒子/建造尘雾）
   │  ├─ background/     # ENV-18..20（1920×1080 远景）
   │  └─ decals/         # ENV-29（Boss 刻印）
   ├─ prompts/
   │  └─ world/          # 每资产一个提示词/溯源记录 md（与资产同一 PR 提交）
   └─ manifest/
      └─ world_manifest.json   # 溯源清单，仅收录 approved 资产
```

`assets/art/world/**` 之外不得存放世界类美术文件；生成中间产物（raw/review）不入库，留在美术本地或外部盘。

### 9.3 导入设置建议（Godot 4.7，GL Compatibility，像素完美）

- 项目级：`rendering/textures/canvas_textures/default_texture_filter = 0`（Nearest），窗口拉伸模式 `canvas_items` + 整数缩放。
- 像素类资产（≤64 px 全部 tile/精灵/粒子）导入覆盖：Filter=Nearest（继承默认）、Mipmaps=Off、Compress=**Lossless**、Detect 3D=Off、Premultiplied Alpha=Off、**Fix Alpha Border=On**（防图集渗色）。
- 三张 1920×1080 远景插画：Filter=**Linear**（仅此三张按资产覆盖为 Linear，避免高清插画马赛克化）、Compress=Lossless、Mipmaps=Off。
- 图集单张 ≤ 2048×2048 px；2D 资产一律不启用 VRAM 压缩（离线单机，保真优先、包体其次）。
- TileSet 终稿：由运行时代码建图集改为外置 `.tres` TileSet 引用上述图集；**source_id 映射冻结**（见 9.4）。

### 9.6 溯源与审批流程（硬门禁）

```text
本合同（environment-assets.md）
  → 美术按资产生成（AI 生成或手绘），提示词/过程记录写入 assets/art/prompts/world/<asset_id>.md

  → 人工审批：负责人在 world_manifest.json 记 approved/approver/date
  → 入库 assets/art/world/**（仅 approved）+ 对应程序接线任务派发
```

- `world_manifest.json` 每条记录：`asset_id`、`file`、`source_model`（或 `handmade`）、`prompt_file`、`approved`、`approver`、`date`。
- 未过审批的资产一律不得进入 `res://assets/`，也不得被场景引用。
