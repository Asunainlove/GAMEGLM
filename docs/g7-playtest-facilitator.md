# G7 试玩主持脚本与复述检验题

> 用途：真人 / 外部玩家试玩主持一页稿。对齐 `docs/g6-g7-human-gates-guide.md` §2.1 与 `docs/rc-playthrough-record.md` §A–§B。
> **禁止捏造**：本文件不含真实试玩结果；用时、复述勾选、签署只写入 `docs/rc-playthrough-record.md`（未跑的格子保持空白）。
> 目标时长：**45–60 分钟 / 路线**。单路线建议上限 75 分钟（超则记入卡点）。

## 0. 启动与键位

| 项 | 说明 |
|---|---|
| 构建 | 优先 `build/starsoil/starsoil.exe`；否则 Godot 编辑器 F5 |
| 新周目 | 标题「新游戏」；确认存档目录已清空（记录表 §0） |
| 移动 | `WASD` / 方向键 |
| 采集 | **左键**点高亮矿脉 |
| 建造选择 | **数字键 1–6** 切换建筑 |
| 放置 | **右键** 或 `F` |
| 背包 / 合成 | `I`（材料不足时看配方，如定神雾） |
| 战斗 | 回合制：点击行动按钮 |
| 存读档 | 菜单「保存」→ 完全退出 → 标题「继续」；「重新开始」应归零 |
| 建议存档点 | ① 锚居工坊后 ② 回响舱激活后 ③ Boss 战前（对照记录表 §A.4） |

### 建筑顺序提示（BuildBar）

锚块 → 锚居工坊 → 尘精炼器 / 稳定塔 / 共鸣织机 → **回响舱**（需房间+供电；断电时 BuildBar 红点可感知）。

### 遭遇顺序

1. `encounter_first_drift`（漂移群）
2. `encounter_husk_ambush`（残壳伏击）
3. `encounter_leviathan`（辉砂巨兽 / Boss，两阶段）

## 1. 公共链路（三路线共用，每路线各走一遍）

按序推进；卡住时在下方「卡点记录」写阶段与现象，**勿编造用时**。

1. 启动至可操作世界（目标 ≤60 秒）；序章降落事件自动触发。
2. 按提示移动 / 放置 / 合成；矿脉覆盖层可辅助找矿。
3. **左键**采尘矿 → 触发首次采集引导 → 数字键选 **锚块** + **锚居工坊**，右键放置。
4. 继续采晶片 / 核矿；`I` 合成定神雾（若提示材料不足）。
5. 建造并供电：尘精炼器、稳定塔、共鸣织机；激活 **回响舱**（`echo_chamber_active`）。
6. 打完前两场遭遇（回合制按钮）。
7. 进入 **三次选择**（见 §2 各路线选项；选择后注意角色回应台词变化）。
8. 决战 Boss → 核对结局标题文案。
9. （可选同周目或读档）菜单保存 → 重启 →「继续」字段一致；「重新开始」归零。

**检查点勾选位置**：`docs/rc-playthrough-record.md` §A.2 公共链路。

**卡点记录位（主持手记，正式结果誊到记录表）**

| 遭遇 1–2 + 三次选择 | | |

## 2. 三路线脚本（关键差异仅在三次选择与结局）

三次选择出现顺序（数据 ID）：

1. 矿站基调 `event_station_mode` → `station_mode_*`
2. 接近方式 `event_approach` → `approach_*`
3. 政策章程 `event_policy` → `policy_*`

### 2.1 开采线 → 结局：开采纪元（`ending_mining`）

| 次序 | 事件 | 选择文案（点这一项） | 落地 flag |
|---|---|---|---|
| 1 | 矿站运营基调 | 全速开采：产量优先，矿脉的负荷以后再算。 | `station_mode_exploit` |
| 2 | 接近发光矿脉 | 直接勘探：架灯、钻孔，按标准流程推进。 | `approach_direct` |
| 3 | 矿站章程 | 配额开采令：按季度核定产量，超额部分充公。 | `policy_extraction_quota` |

**本线额外检查**

- exploit 后矿脉富集 / 世界回应是否可感知（重生成）。
- 配额后 Boss 压力变化是否可感知（血量 ×1.2 类反馈）。
- BuildBar 断电红点、信任面板数值可见。
- 结局标题精确为：**结局：开采纪元**。

### 2.2 封存线 → 结局：封存之约（`ending_seal`）

| 次序 | 事件 | 选择文案（点这一项） | 落地 flag |
|---|---|---|---|
| 1 | 矿站运营基调 | 封闭封存：暂停扩张，把矿站连同回声一起封进静默里。 | `station_mode_seal` |
| 2 | 接近发光矿脉 | 先礼后探：熄灯静立，等矿脉先开口。 | `approach_diplomatic` |
| 3 | 矿站章程 | 配额开采令：按季度核定产量，超额部分充公。 | `policy_extraction_quota` |

**本线额外检查**

- `approach_diplomatic` 触发 `event_envoy_trust`（信任 +5 分支）可见。
- 公共链路检查点全部走过。
- 结局标题精确为：**结局：封存之约**。

### 2.3 共生线 → 结局：共生曙光（`ending_symbiosis`）

| 次序 | 事件 | 选择文案（点这一项） | 落地 flag |
|---|---|---|---|
| 1 | 矿站运营基调 | 共生共调：按矿脉的呼吸节奏安排开采与回补。 | `station_mode_symbiosis` |
| 2 | 接近发光矿脉 | 直接勘探：架灯、钻孔，按标准流程推进。 | `approach_direct` |
| 3 | 矿站章程 | 矿脉庇护案：划定禁采区……（**需要洛弦信任 ≥40**） | `policy_sanctuary` |

**本线额外检查**

- 庇护案在信任不足时禁用态 / 提示文案可见；够 40 后方可选。
- 共生门提示「距离共生还需 X 点」随信任推进消失。
- 通关条件：洛弦信任 **≥70** + 回响舱已激活 → **结局：共生曙光**。
- 对照（可选读档）：信任 69 或未激活回响舱 → 回落 **结局：封存之约**（`fallback_ending`）。记下**实际**结局，勿改写记录。

## 3. 复述检验题（包2｜外部 / 本人试玩问卷）

对齐 `docs/rc-playthrough-record.md` §A.3 / §B 与 `docs/rc-checklist.md` §7。

### 3.1 开场题（首 5 分钟）

试玩开始后约 5 分钟问（或结束后回溯）：

1. 前 5 分钟有没有卡住、不知道下一步、或想退出？具体是哪一步？
2. 键位是否找得到？（移动 / 左键采 / 数字键建造 / 右键放置 / `I` 背包）

### 3.2 核心假设四项（结局后口头问，勿先念选项）

总问：**「你的采集 / 建造 / 校准改变了什么？」**

主持按玩家口述勾选（记录表 §A.3 四列）：

| # | 复述要点 | 通过样例（玩家能说到大意即可） |
|---|---|---|
| 1 | **地图变化** | 矿脉、建筑落位、供电/断电、覆盖层或世界回应变化 |
| 2 | **角色立场变化** | 洛弦 / 弥砂信任或好感可见变化、台词随选择变化 |
| 3 | **Boss 条件变化** | 三次选择影响决战压力 / 巨兽反应 / 战前态势 |
| 4 | **结局差异** | 能说出本路线结局标题，并意识到另两条会不同 |

### 3.3 外部试玩补充题（可粘贴进记录表 §B）

- 三次选择与结局走向是否可感知、可复述？
- 主观时长相对 45–60 分钟偏快 / 刚好 / 偏慢？
- 中文文案是否可读？有无错别字或不通顺句？

### 3.4 通过建议（裁定参考，非自动填表）

- ≥3 名**非开发**外部玩家，各至少 1 条路线。
- **≥2/3** 玩家复述 **≥3/4** 项核心假设。
- 无路线超过 75 分钟（或超限已记录并由产品裁定）。
- 首 5 分钟无功能性卡死；无 P0（崩溃 / 无法推进 / 存档丢失）。
