## 目标

缺口报告 F2（P2，处置包 W002-GAP5 / 本包 W003-A3）：目标链提示覆盖主线，
但无"首次操作"即时引导（热键 1-6/覆盖层/房间合围）。交付：

1. `Hud.show_hint(text, seconds=4.0)`：屏幕中下方 HintToast 提示条，淡入淡出，
   队列排队逐条显示；一次性（同条不重复）；持久化经注入回调 `hint_seen_callback`
   （缺省无操作；GameSession 注入为经 patch 写 `hint_<id>_seen` 的闭包——表现层
   不直接写状态，由 game_session 的回调执行 patch）。
2. 六个触发点（见提示清单表），条件均含 flag 未置检查。
3. 重开（读档）游戏不重复提示；测试用注入内存回调验证落账。

## 初始现状（审核基线上的实测）

- `hud.gd` 仅有 `flash_notice`（ObjectiveLabel 短暂替换文案），无队列、无一次性
  语义、无持久化通道；O 覆盖层由 `world.gd` 切换（本包禁改 src/world）。
- `game_session.gd` 六条链路均无首次操作提示触发点。
- `ui_hud.tscn` 无提示条节点。

## 设计决策

1. **文案与 hint id 单一来源在 hud.gd**：六个提示文案常量（`HINT_*_TEXT`）+
   `HINT_IDS_BY_TEXT` 查表 + `hint_id_for(text)` 静态派生（模板化放置提示按前后缀
   归一为 `place`，与建筑名无关；未知文案退化为 `text_<hash>` 兜底，生产六个
   触发点全部命中查表/模板）。game_session 触发点引用 `Hud.HINT_*_TEXT`，
   flag 名统一走 `Hud.HINT_FLAG_FORMAT`（`hint_%s_seen`）。
2. **一次性两层保证**：HUD 会话内 `_shown_hint_ids` 去重（同 id 不复播）+
   快照 flags 只读检查（读档/重开后 `hint_<id>_seen` 已置位则跳过）。落账时机为
   首次接受入队时同步回调（提示未播完即存档也不会丢标记）。
3. **O 覆盖层触发点在 HUD 内但不消费输入**：`_unhandled_input` 新增
   `toggle_overlay` 分支，刻意不 `set_input_as_handled`——覆盖层显隐归属仍是
   world（未改 src/world），HUD 只提示。暂停期间 world 不响应 O 键，故提示同样
   跳过，与实际行为对齐。
4. **可测性**：队列完成路径拆为 `_on_hint_hold_timeout()`（停留超时→淡出）与
   `_on_hint_fade_out_finished()`（隐藏→泵下一条），生产分别由 HintTimer 与
   淡出 tween 的 finished 驱动，测试直接调用（任务书"用可控 timer 或直接调
   完成方法"）。开局 2s 提示由 GameSession 的 one_shot `MoveHintTimer` 驱动，
   测试直接调 `_show_move_hint_if_due()`。

## 限制

1. `battle` 提示在遭遇触发瞬间弹出；模态层（layer 50）高于 UILayer（layer 20），
   战斗场景铺开后提示条被遮挡——按任务书"遭遇触发前"的触发点语义实现，
   战斗内引导纵深留给 F1 内容量包复核。
2. 未知文案的 hint id 退化为 `text_<hash>`（生产六个触发点全部命中查表/模板，
   兜底仅为任意调用的健壮性；`text_*` 形态 flag 同样满足一次性语义）。
3. 暂停期间按 O 不弹提示（world 此时本就不切换覆盖层）；HUD 为
   PROCESS_MODE_ALWAYS，HintTimer/淡出 tween 暂停中仍推进，菜单打开时提示条
   完成收起属预期。
4. `move` 提示计时器挂在 GameSession（pausable）下，2s 为纯游戏时时间，
   暂停会顺延。
5. "重新开始"会归零全部 flags，属全新一局，提示按设计重新出现；
   "重开（读档）不重复"由 flag 检查保证并有测试覆盖
   （`test_move_hint_skipped_when_flag_already_seen` /
   `test_show_hint_skips_when_flag_already_seen_in_snapshot`）。
6. HintToast 视觉为主题灰盒（PanelContainer + 主题字体），正式美术接入
   （G6）前不申请 approved 资产状态。
