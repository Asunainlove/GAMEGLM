## 实现

**`src/audio/audio_director.gd`（`class_name AudioDirector extends Node`，纯代码）**

- `_ready` 代码创建全部子节点（不经场景）：`BgmPlayer`（AudioStreamPlayer）+ `SfxPool`
  （Node 下 8 个 AudioStreamPlayer，`Slot00`–`Slot07`）。
- **总线绑定**：`_effective_bus()` 遍历 `AudioServer` 总线判存在性（不用 `get_bus_index`
  以免对缺失总线打错误日志）——BGM/SFX 总线存在即绑定，缺省布局（仅 Master）回退 Master。
  协调者提交 `default_bus_layout.tres`（Master→BGM/SFX，建议见 docs §1）后运行时自动绑定，无需改码。
- **`play_bgm(track_id, fade_seconds = 1.0)`**：经 `track_resolver`（Callable 注入）取流；
  同曲重入（含换曲淡入进行中）忽略；换曲 kill 旧 Tween → 淡出旧流至 -60 dB（0.5×fade）→
  换流起播 → 淡入至 0 dB（0.5×fade）（Tween 控制 `volume_db`，headless 按帧推进）；
  `fade_seconds <= 0` 或当前无播放时立即起播。
- **`play_sfx(sfx_id, volume_offset_db = 0.0)`**：8 槽轮转（`_next_sfx_index` 环绕，
  观察口 `sfx_pool_cursor()`）；槽位 stop → 换流 → 设音量 → play（旧音自然截断）。
- **resolver 契约**：未注入（`is_valid() == false`）/ 返回 null / 返回非 AudioStream →
  `push_warning` 并忽略该次请求，且不推进 cursor、不写 history（无资产时零崩溃零副作用）。
- **`current_bgm()` / `stop_all()` / `set_master_muted(muted)` / `is_master_muted()` /
  `bgm_history`（最近 8 条）**：stop_all 重置当前曲目选择（重播同曲不算重入）但保留历史；
  静音走 `AudioServer.set_bus_mute(Master)`。
- **挂点约定**（类头文档注释 + docs §3）：app 层（A10）实例化并注入 resolver；事件/战斗/建造/
  存档经调用方注入使用；音频为纯表现状态，不进 GameState/SaveService/StatePatch。

**`docs/art/audio-assets.md`（简体中文规范）**

- §1 总线布局（Master→BGM/SFX + 降级行为说明，project.godot 留给协调者）；

- §4 BGM 5 首（bgm_title 希望与余绪 / bgm_explore 琉砂海旷野 / bgm_build 锚居暖意 /

  两段同 BPM 同调，对齐 `combat_engine.gd` 的 `phase_change`（`lumen_leviathan` HP ≤ 50% →
  `leviathan_p1`））——每首含资产 ID/触发点/格式/时长/风格/混音/验收/优先级/工时；

**`tests/unit/test_audio_director.gd`（12 条，headless）**

- 节点契约：`_ready` 代码建 BgmPlayer + 8 槽池；
- 总线：注入假总线（`AudioServer.add_bus`，after_each 清理）时绑定 BGM/SFX；缺省布局回退 Master；
- play_bgm：状态断言（current_bgm / stream / playing / volume_db / history）、同曲重入忽略
  （resolver 只调 1 次）、换曲淡出淡入（同步断言旧流仍在播 → await 0.6 s 后新流 + 0 dB + playing）、
  history 只留最近 8 条；
- play_sfx：池轮转索引（前 3 槽占用 + 9 次播放环绕回槽 0）、volume_offset_db 落槽；
- 坏路径：resolver 缺失 / 返回 null / 返回非 AudioStream 三分支零崩溃零副作用；
- muted 切换（AudioServer Master 总线真实静音）；stop_all 停全部并允许重播。
- 测试替身模式与既有惯例一致：`load()` 运行时加载（RED 隔离解析噪声）、替身宿主存测试实例
  字段保活（Callable 只持 ObjectID）、哑流为带 10 s 静音数据的 `AudioStreamWAV`。

## 已知限制与偏差

1. **预存偶发 flake（非本包引入，实测复现于无本包改动的基线）**：全量套件在 `tests/unit/
   test_integration.gd` 存在环境/时序敏感的偶发失败（`test_trust_locked_option_...`、
   `test_place_chain_...`、`test_encounter_chain_defeat_...` 等），机器高负载时概率升高。
   实测：**移除本包测试文件后的原基线连跑 4 次 = 1 通过 + 3 次 flake**（含一次 15 失败、
   `ContentDB.ids_of` 返回空数组的启动序 flake）；本包 GREEN 后 fresh 单跑通过（472/472 ×2、
   Verify-Toolchain 的 GUT_DEFAULT PASS）。本包 12 条测试与其无共享状态（仅操作 AudioServer
   总线并在 after_each 还原）。该 flake 不在允许路径内（禁改 `tests/unit/` 既有文件），留给协调者。
2. BGM/SFX 总线未在 `project.godot` 注册（本包禁改）：框架按 `_effective_bus` 回退 Master
   运行，docs §1 已给协调者布局建议；总线就位后无需改代码。
3. `bgm_history` 与音频播放均为纯表现状态，不落账（设计决定，避免 Save schema 变更）。
4. 本包不接线任何调用点（任务边界）：接线清单在 docs §6，归 W003-A10+。
